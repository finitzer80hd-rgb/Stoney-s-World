# Stoney's World

An original Unreal Engine 5 open-world action prototype.

## Project status

This repository was empty when setup was attempted. This initial commit establishes the project and development plan; it is not a packaged game build.

## Target
- Unreal Engine 5.5
- Windows 10/11
- Visual Studio 2022 with the Game development with C++ workload

## Gameplay roadmap
- Fast tactical sprint, slide, jump and air control
- Grapple hook with pull, reel, swing and release
- Parachute and wingsuit foundations
- Drivable vehicles and basic traffic
- Wandering NPCs, delivery missions and wanted-level prototype

## Build
Open `StoneyWorld.uproject` with Unreal Engine 5.5, allow project files to be generated, build the `Development Editor | Win64` target, then press Play. Source-only prototype; a Windows executable must be packaged on a machine with Unreal Engine installed.
